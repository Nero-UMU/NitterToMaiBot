# NitterToMaiBot

通过 Nitter 获取推特内容，并由 MaiBot 转发到 QQ 群。

## 基本功能

- 每个 QQ 群可以独立订阅多个推特账号，也可以独立暂停或恢复推送。
- 默认每 600 秒（10 分钟）扫描一次 Nitter，并把新推文及其图片、视频等媒体发送到订阅群。
- 默认同一轮向同一个群发送 1 条推文时普通发送，2 条及以上时打包为 QQ 合并转发。
- 可设置北京时间静默时段；期间发现的新推文会持久化暂存，并在静默结束后的下一轮扫描中一次性合并转发。
- 支持在 QQ 群聊和私聊中获取指定账号的最新推文或解析指定推文链接。
- 默认自动解析群聊和私聊中的推文链接；识别成功后会阻止 LLM 重复回复该链接。
- 可使用 MaiBot 已配置的模型把推文正文翻译成简体中文，并附在原文下方。
- 支持设置是否转发账号的转推、单次推文数量、媒体大小上限和每群订阅上限。
- 后台订阅列表仅供查看；群内命令产生的订阅变更会自动同步到后台。

## 快速开始

### 安装插件

进入 MaiBot 的 `plugins` 目录并克隆本项目：

```bash
cd /path/to/MaiBot/plugins
git clone https://github.com/Nero-UMU/NitterToMaiBot.git
```

等待 MaiBot 识别并加载插件，然后在后台插件管理页面打开“Nitter 推文转发”。

插件依赖会按照 `_manifest.json` 由 MaiBot 安装，无需手动安装 Python 包。首次加载时，Runner 会根据插件配置模型生成本地 `config.toml`。

插件 ID 为 `github.nero-umu.nitter-to-maibot`；从旧 ID 升级时，插件会自动迁移原有订阅和去重状态。

### 基本设置

在 MaiBot 后台打开本插件并完成以下设置：

- **启用插件**：开启自动扫描、自动转发和自动链接解析。
- **Nitter 实例地址**：默认使用 `https://nitter.net`，也可以填写自己的 Nitter 地址。
- **发送机器人 QQ 号**：仅在 MaiBot 同时接入多个 QQ 机器人时需要指定。
- **轮询间隔（秒）**：默认 `600`，即每 10 分钟扫描一次。
- **合并转发阈值**：默认 `1`，即超过 1 条时打包发送。
- **启用静默时段**：默认关闭；默认范围为北京时间 `00:00`–`06:00`，期间只扫描和暂存，结束后的下一轮扫描统一发送。
- **启用推文翻译**：默认关闭；开启后为自动推送、手动获取和链接解析结果增加中文翻译，翻译失败时直接发送原文。
- **翻译模型**：选择 `utils`、`replyer` 或 `planner` 模型任务，推荐使用 `utils`。
- **翻译提示词**：默认已填写内置翻译要求，可以在后台直接修改并用于之后的所有推文翻译。
- **媒体大小上限（MiB）**：默认 `10`，限制单张图片下载并内嵌发送的大小。

订阅账号和目标群无需在后台手动填写，请直接使用下面的群内命令管理。

## 命令

- `/推特帮助`：查看全部可用命令、参数和简要说明。英文别名：`/twitter_help`。

### 订阅管理命令

以下命令只能在 QQ 群聊中使用：

- `/推特关注 <账号1> [账号2 ...]`：为当前群订阅一个或多个推特账号，单次最多添加 10 个；账号可带或不带 `@`。英文别名：`/twitter_follow`。
- `/推特取关 <账号1> [账号2 ...]`：取消当前群对一个或多个账号的订阅。英文别名：`/twitter_unfollow`。
- `/推特订阅`：查看当前群的推送状态、订阅账号和推特名称；超过 20 个账号时自动使用 QQ 合并转发。英文别名：`/twitter_follows`。
- `/推特推送 开启|关闭`：开启或暂停当前群的自动推送，不会删除已有订阅。英文别名：`/twitter_push on|off`。

### 推文获取与解析命令

以下命令可在 QQ 群聊或私聊中使用：

- `/推特推文 <账号> [数量]`：获取该账号最新的若干条推文；数量默认为 `1`，且不会改变自动轮询的去重记录。英文别名：`/twitter_posts`。
- `/推特解析 <推文链接>`：解析一条 Twitter、X 或 Nitter 推文链接，并发送正文及媒体。英文别名：`/twitter_parse`。

开启“自动解析推文链接”后，也可以直接在群聊或私聊中发送推文链接，无需输入 `/推特解析`。

### 运行命令

- `/nitter_status`：查看插件是否启用、Nitter 地址、订阅数量、静默状态、待发送数量、合并转发阈值和轮询间隔。
- `/nitter_scan`：立即执行一次订阅扫描并返回统计结果；静默期间只暂存新推文，不会绕过静默设置。

## 使用示例

```text
/推特关注 elonmusk OpenAI
/推特订阅
/推特推文 elonmusk 3
/推特解析 https://x.com/elonmusk/status/1234567890
/推特推送 关闭
```

## 权限与能力

- `chat.open_session`：打开目标 QQ 群的真实聊天流。
- `send.text`、`send.image`、`send.custom`：发送推文正文、图片、视频和其他附件。
- `send.forward`：发送多条推文或较长订阅列表的 QQ 合并转发。
- `llm.generate`：仅在开启推文翻译后调用所选 MaiBot 模型任务。

插件没有向 LLM 注册 Tool；聊天交互由命令和推文链接拦截处理。

## 故障排查

- **插件未出现或加载失败**：确认目录为 `plugins/NitterToMaiBot/`，并检查 MaiBot、插件 SDK 版本和加载日志。
- **Nitter 返回 404 或连接失败**：在服务器上确认配置的 Nitter 实例可访问，并检查实例是否支持目标账号和状态页。
- **没有自动推送**：确认插件、当前群推送和账号订阅均已开启；同时检查轮询间隔、静默时段和 `/nitter_status` 中的待发送数量。
- **命令无法使用**：群订阅命令只能在 QQ 群聊中执行，并受“允许群内管理订阅”和“仅限本地操作员管理”设置影响。
- **链接仍交给 LLM**：确认插件已启用，并开启“自动解析推文链接”。
- **翻译模型返回内容安全错误**：推文正文和原文链接可能触发模型服务商风控，可关闭翻译或更换模型任务。
- **图片或视频发送失败**：检查媒体大小上限、Nitter 媒体地址以及 QQ 适配器能否访问对应 URL。

## 注意事项

> 插件会在聊天窗口中发送推文内容和原文链接，这些信息可能进入聊天上下文，并触发部分模型服务商的内容安全策略。请根据实际使用环境谨慎选择模型。
